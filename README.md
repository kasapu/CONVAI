# CONVAI

A conversational AI project designed to work seamlessly with modern AI code assistants.

## AI Code Assistant Access

This repository is configured to work with various AI code assistants including:

- **Claude Code** - Anthropic's code assistant
- **OpenAI Codex** - OpenAI's code completion engine  
- **CodeGuide** - AI-powered code guidance tools
- **GitHub Copilot** - GitHub's AI pair programmer

## Permissions & Usage

This project is licensed under the MIT License, which grants broad permissions for use, modification, and distribution. AI code assistants are explicitly permitted to:

- Read and analyze the codebase
- Suggest code improvements and modifications
- Generate code snippets based on existing patterns
- Assist with documentation and testing
- Help with refactoring and optimization

## Getting Started

```bash
git clone https://github.com/kasapu/CONVAI.git
cd CONVAI
```

## AI Assistant Guidelines

When using AI code assistants with this repository:

1. Follow the existing code style and patterns
2. Ensure all suggestions align with the project's MIT license
3. Test any AI-generated code thoroughly
4. Document AI-assisted changes appropriately
5. Review AI suggestions before implementation
