# AI Assistant Configuration

This directory contains configuration files and documentation for AI code assistants.

## Supported AI Assistants

- Claude Code (Anthropic)
- OpenAI Codex (OpenAI)  
- CodeGuide (AI code guidance)
- GitHub Copilot (GitHub)

## Configuration Files

- `permissions.json` - Detailed permissions for AI access
- `guidelines.md` - Specific guidelines for AI code generation
- `patterns.json` - Code patterns and style preferences
- `context.md` - Project context for AI understanding

## Usage

AI assistants can reference these files to better understand:
- Project structure and conventions
- Preferred coding patterns
- License and permission requirements
- Development workflow expectations
