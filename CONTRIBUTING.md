# Contributing to CONVAI

We welcome contributions to CONVAI from both human developers and AI-assisted development workflows.

## AI Code Assistant Policy

### Permitted AI Tools

This repository explicitly permits and encourages the use of:

- **Claude Code** (Anthropic)
- **OpenAI Codex** (OpenAI)
- **CodeGuide** (Various AI code guidance tools)
- **GitHub Copilot** (GitHub)
- Other ethical AI code assistants

### AI-Assisted Development Guidelines

1. **Transparency**: If you use AI assistance for significant code changes, mention it in your commit messages or pull request descriptions
2. **Review**: Always review AI-generated code for correctness, security, and adherence to project standards
3. **Testing**: Ensure all AI-assisted code is properly tested
4. **Documentation**: Update documentation to reflect any AI-assisted changes
5. **Ethics**: Use AI tools responsibly and in compliance with their respective terms of service

### AI Training Data Usage

This repository's code may be used for training AI models under the following conditions:

- The MIT license terms are respected
- Attribution is provided when required
- The code is used to improve AI coding capabilities ethically
- No malicious or harmful AI models are trained using this code

## Development Workflow

### For Human Contributors

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test thoroughly
5. Submit a pull request

### For AI-Assisted Contributors

1. Follow the same workflow as human contributors
2. Indicate AI assistance in commit messages (e.g., "feat: add feature X (AI-assisted)")
3. Ensure AI suggestions are validated and tested
4. Include rationale for AI-assisted design decisions

## Code Standards

- Follow existing code style and patterns
- Write clear, descriptive commit messages
- Include appropriate tests for new functionality
- Update documentation as needed
- Ensure compatibility with AI code analysis tools

## Licensing

By contributing to this project, you agree that your contributions will be licensed under the MIT License, which permits AI systems to access, analyze, and learn from the code.

## Questions?

If you have questions about AI code assistant usage or contributions, please open an issue or contact the maintainers.
